# 截图

把两张实机截图放在这里（建议 1080 宽、JPEG/PNG）：

- `strip.jpg`：输入框上方的胶囊（正常状态 + 余额不足状态各一张更好）
- `panel.jpg`：用量面板

然后在 `market/local-token-meter.json` 的 `screenshots` 里填 raw.githubusercontent 链接，例如：

```json
"screenshots": [
  "https://raw.githubusercontent.com/ZiiMoy/dsh-go-token-meter/main/docs/strip.jpg",
  "https://raw.githubusercontent.com/ZiiMoy/dsh-go-token-meter/main/docs/panel.jpg"
]
```
